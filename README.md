# 棧板明細估算系統

依照包材規則，把出貨品項的件數自動拆分成一筆筆棧板明細，協助在公司快速分類、排板。

## 功能

- 圖形介面選擇三個 Excel 檔：條件規則、需要整合的資料、輸出結果
- 同一「物料＋批次」的件數自動加總合併
- 依物料代碼最後 5 碼比對包材規則，按「分裝」數量拆成多筆明細
- 拆分後剩 1 件時改用「單一包裝」(例如 DRUMS → DRUM)
- 查無對應規則的物料仍會輸出，包材欄留空方便人工處理
- 結果寫入輸出檔的「工作表2」，搭配「工作表1」的公式組成棧板清單
- 檔案不存在、欄位錯誤、檔案被占用時會在介面顯示紅字提示

## 安裝

需要 Python 3.10 以上。

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 執行

```bash
python 棧板明細估算系統v3.0.py
```

或在 VS Code 按 F5，選「執行棧板明細估算系統」。

### 打包成 exe

```bash
pip install pyinstaller
pyinstaller -F -w 棧板明細估算系統v3.0.py
```

產生的 exe 在 `dist/` 資料夾。

## 使用方式

1. 選擇**條件規則**的 Excel 檔 (範例：`規則檔.xlsx`)
2. 選擇**需要整合**的 Excel 檔 (範例：`讀取檔.xlsx`)
3. 選擇**輸出結果**的 Excel 檔 (範例：`寫入檔.xlsx`)
4. 按「提交」或 Enter，出現綠字「處理完成」即完成

### Excel 欄位格式

**條件規則檔** (第一個工作表)

| 包材 | 分裝 | 包裝 | 單一包裝 |
|------|------|------|----------|
| PC   | 32   | DRUMS | DRUM    |
| CN   | 16   | BOXES | BOX     |

- 包材：物料代碼最後 5 碼中包含的代號
- 分裝：每筆明細的數量上限
- 包裝／單一包裝：數量大於 1 與剛好 1 件時使用的包材名稱

**需要整合的檔案** (第一個工作表)

| 物料 | 批次 | 件數 |
|------|------|------|
| PV8000000PC | 2430021 | 15 |

**輸出結果檔**：寫入「工作表2」，欄位為 品號／批號／數量／包材。

### 拆分範例

物料 `PV8000000PC` 共 70 件，規則 PC 分裝 32：

| 品號 | 數量 | 包材 |
|------|------|------|
| PV8000000PC | 32 | DRUMS |
| PV8000000PC | 32 | DRUMS |
| PV8000000PC | 6  | DRUMS |

## 常見問題

**Q：出現「輸出結果的檔案被占用」？**
A：輸出的 Excel 正在開啟中，請先關閉再按提交。

**Q：出現「請檢查第一列名稱」或「請確認 Excel 欄位名稱」？**
A：Excel 第一列的欄位名稱要和上面格式完全一致 (包含全形、半形)。

**Q：某些品項的包材是空白？**
A：該物料最後 5 碼找不到對應的包材代號，請在規則檔新增一列。

**Q：批次前面的 0 不見了？**
A：程式以文字讀取批次欄，若 Excel 中原本就存成數字，請先把該欄格式改為「文字」。
