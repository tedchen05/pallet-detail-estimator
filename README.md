# 棧板明細估算系統

依照包材規則，把出貨品項的件數自動拆分成一筆筆棧板明細，協助在公司快速分類、排板。

## 功能

- 依「① 條件規則 → ② 需要整合 → ③ 輸出檔案」三個步驟選擇 Excel 檔
- 程式旁邊有 `規則檔.xlsx`、`讀取檔.xlsx`、`寫入檔.xlsx` 時**開啟就自動帶入**，這三個範例檔也是不會用時可以參考的原檔
- **記住上次的選擇**：估算成功後記下三個檔案與「使用原檔名」的勾選，下次開啟直接帶入；記錄的檔案不在了才改用上面的預設檔
- 選好檔案**立即檢查**，綠字顯示規則數、資料筆數；欄位缺少或檔案被占用時紅字說明原因
- 同一「物料＋批次」的件數自動加總合併
- 依物料代碼最後 5 碼比對包材規則，按「分裝」數量拆成多筆明細
- 拆分後剩 1 件時改用「單一包裝」(例如 DRUMS → DRUM)
- 估算後右側顯示明細筆數與**明細預覽**，找不到包材規則的品項以橘色標示並列出物料代碼
- **預設原檔不動**：另存成加上今天日期的新檔，例如 `寫入檔.xlsx` → `寫入檔_20261004.xlsx`；勾選「使用原檔名」則直接寫入原檔
- 明細寫入新檔「工作表2」的 A～D 欄，會先清掉範本裡的舊明細，其他欄位與公式不動
- 明細預覽附「序號」欄，**未滿分裝的餘數列以藍色底標示**，方便一眼看出哪幾板沒裝滿
- 「開啟輸出檔」一鍵用 Excel 開啟剛另存的新檔

## 安裝

需要 Python 3.10 以上。

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 執行

```bash
python pallet_gui.py
```

或在 VS Code 按 F5，選「執行棧板明細估算系統」。

### 打包成 exe

```bash
pip install pyinstaller
pyinstaller -F -w -n 棧板明細估算系統 pallet_gui.py
```

產生的 exe 在 `dist/` 資料夾。

## 使用方式

1. 確認左側三個步驟都是綠色 ✓ (範例檔放在程式旁邊會自動帶入，要換檔案按「選擇…」)
2. 按「開始估算」或 Enter
3. 右側顯示「N 筆明細」與明細預覽即完成，按「開啟輸出檔」查看另存的新檔
4. 有橘色提示時，代表這些物料找不到包材規則，請到規則檔補上後再估算一次

### Excel 欄位格式

**條件規則檔** (第一個工作表)

| 包材 | 分裝 | 包裝 | 單一包裝 |
|------|------|------|----------|
| PC   | 32   | DRUMS | DRUM    |
| CN   | 16   | BOXES | BOX     |

- 包材：物料代碼最後 5 碼中包含的代號
- 分裝：每筆明細的數量上限
- 包裝／單一包裝：數量大於 1 與剛好 1 件時使用的包材名稱

**需要整合的檔案** (第一個工作表)

| 物料 | 批次 | 件數 |
|------|------|------|
| PV8000000PC | 2430021 | 15 |

**輸出檔案**：明細寫入「工作表2」，欄位為 品號／批號／數量／包材。
- 不勾「使用原檔名」(預設)：另存成 `原檔名_今天日期.xlsx`，原檔不動；同一天重複估算不會覆蓋，依序存成 `_2`、`_3`…
- 勾選「使用原檔名」：直接寫入原檔，不另存新檔

### 拆分範例

物料 `PV8000000PC` 共 70 件，規則 PC 分裝 32：

| 品號 | 數量 | 包材 |
|------|------|------|
| PV8000000PC | 32 | DRUMS |
| PV8000000PC | 32 | DRUMS |
| PV8000000PC | 6  | DRUMS |

## 常見問題

**Q：出現「被占用，請先關閉檔案再試」？**
A：該 Excel 正在開啟中，請先關閉再按「開始估算」。

**Q：出現「缺少欄位：…」？**
A：Excel 第一列的欄位名稱要和上面格式完全一致 (包含全形、半形)，也請確認沒有選錯步驟的檔案。

**Q：出現「第N列件數…不是正整數」或「第N列物料空白」？**
A：該列資料有問題，程式不會略過，請到 Excel 對應的列修正。件數、分裝都要是大於 0 的整數；整列空白的列會自動略過。

**Q：某些品項的包材是空白？**
A：該物料最後 5 碼找不到對應的包材代號，請在規則檔新增一列。

**Q：批次前面的 0 不見了？**
A：程式以文字讀取批次欄，若 Excel 中原本就存成數字，請先把該欄格式改為「文字」。

**Q：想讓程式回到預設的三個範例檔？**
A：刪除程式旁邊的 `pallet_settings.json` 再重新開啟即可，這個檔案只記錄上次選的檔案，刪掉不影響程式。

## 檔案說明

```
pallet-detail-estimator/
├── pallet_gui.py          # 視窗介面 (主程式，執行這個)
├── pallet_core.py         # 核心功能：讀取規則、合併件數、拆分明細、寫入 Excel
├── requirements.txt       # 需要安裝的套件
├── 規則檔.xlsx            # 範例：條件規則
├── 讀取檔.xlsx            # 範例：需要整合的資料
├── 寫入檔.xlsx            # 範例：輸出檔案 (含棧板清單公式)

    ├── launch.json        # VS Code 按 F5 的執行設定
    └── extensions.json    # 建議安裝的 VS Code 擴充功能
```
